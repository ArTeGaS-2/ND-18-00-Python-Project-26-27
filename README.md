## Вибір наповнювачів — 25.10.2026

Додано порівняння назв без урахування регістру, перевірку кількості в наявності, завершення через `-` і показ вибраних назв. Вкладена функція повертає ознаку продовження для циклу `while`. `python main.py` запускає лише вибір наповнювачів.

У словнику перше число — кількість, друге — ціна. Невідома назва або позиція з нульовою кількістю не додається; окремого повідомлення про це поки немає. Запаси під час вибору не зменшуються.

Уроковий код збережено без виправлення: умова `len(self.client_topings) <= self.max_topings_count` допускає ще одне введення, коли вже набрано 5 позицій, тому може прийняти шосту. Цю межу перевірено разом із різним регістром, нульовим запасом і завершенням через `-`. Поточні зміни взято з власної папки НД-18-00.
